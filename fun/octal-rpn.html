How it reads

Order
Values first, operator last. 1 4 / divides 1 by 4. Put a space between every token.
Digits
Only 0–7. 10 is eight, 100 is sixty‑four.
Fractions
Base 8 after the point too, so 0.4 is one half and 0.2 is one quarter.
Negative values
NEG flips the sign of the value you're keying in and writes it flush against the digits: 10 -5 +. A - with spaces around it subtracts.
Repeating results
Parentheses mark digits that run forever: 1 3 / gives 0.(25).
